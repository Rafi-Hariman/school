Apa itu CSS?

CSS (Cascading Style Sheets) adalah bahasa yang digunakan untuk mengatur tampilan dan gaya elemen HTML pada halaman web.

Dengan CSS kita dapat mengatur warna, ukuran font, jarak, latar belakang,

  • Inline CSS ditulis langsung di atribut style elemen HTML
  • Internal CSS ditulis di dalam tag <style> di bagian <head>
  • External CSS ditulis di file .css terpisah, dihubungkan dengan <link>
  1. Selector Tag memilih berdasarkan nama elemen HTML
  2. Selector Class memilih berdasarkan atribut class
  3. Selector ID memilih berdasarkan atribut id
Properti Fungsi Contoh Nilai
color Warna teks red, #333, rgb(0,0,0)
background-color Warna latar belakang blue, #fff
font-size Ukuran font 16px, 1em, 1.2rem
margin Jarak luar elemen 10px, 0 auto
padding Jarak dalam elemen 8px 16px
border Garis tepi elemen 1px solid #ccc
display Tipe tampilan elemen block, inline, inline-block
